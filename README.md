# eusate-frontend

## Overview
Frontend for eusate

## Installation
1. Clone this repository
2. Run `npm i` or `npm install` in the terminal
3. Create a `.env` in the root directory of the project and updated it as shown in the `.env.example` file present in the repo.
4. Run `npm run dev` in your terminal to start server and open localhost:3000 in your browser.
